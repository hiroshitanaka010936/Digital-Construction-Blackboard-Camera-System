# GitHub Pages版（連続撮影・自動保存）

## 仕様
- 撮影ボタンを押すたび、黒板合成JPEGを生成します。
- 結果画面へ移動せず、カメラ画面を維持して連続撮影できます。
- JPEGはブラウザのダウンロード処理を自動実行します。通常は「ファイル」Appのダウンロード先に保存されます。
- 対応環境では、同時にWebアプリ専用ストレージ（OPFS）へバックアップします。
- ファイル名末尾は `_001`, `_002` のように連番になります。

## 更新方法
このZIP内の `index.html`、`manifest.webmanifest`、`sw.js` をGitHubリポジトリ直下へ上書きし、Commitしてください。

## iPhone上の制限
Webアプリから「写真」Appのカメラロールへ無確認で直接保存することはできません。完全自動で写真Appへ保存するには、Swift/SwiftUIによるネイティブiOSアプリ化が必要です。このPWA版は「ファイル」側への自動ダウンロードを採用します。
